Phone lookup

A number is normalized, checked locally, then read from MongoDB. Veriphone is called only when there is no fresh row. A stored result is reused for 90 days. The carrier on the screen is the carrier Veriphone returned. This app does not assign one.

Open Swagger UI to inspect the request body and try the same endpoints.

Leave region empty only when the number starts with + or 00. A number with neither a country code nor a region is rejected before any lookup. A national number such as 9876543210 needs a region, and that region is the country used. “Valid” means the number fits that country’s numbering plan. It does not mean the line is active.

Batch lookup

Upload a .csv or .txt file with 10 to 20 lines. Each line is the number, then a comma, then that number’s region. There is no separate region box, because every line carries its own.

Example lines: 9876543210,IN or +14155552671. A line with a country code can leave the region empty. A line with neither is rejected and the lookup service is not called. A header row phone,region is ignored. .xlsx and other file types are rejected.
